# 04 · 七条路径的实测关闭记录

目标：在两台机器、游戏机零安装的前提下，从网络侧取得对局数据。

下面每一条都是**跑过的实验**，附观察到的现象。

---

## 1. 网关抄包 → ✗

网关能看到全部流量，但从第一个对局包起就是 AEAD 密文。
密钥在连接建立阶段通过 TLS 下发，不在 UDP 流里。

**现象**：116,747 个对局包，最小 41 字节，无一 < 38；
全部从第 0 字节起均匀分布；跨包异或无结构，无密钥流复用。

---

## 2. TLS 中间人 → ✗

做法：生成测试 CA → 装入 `LocalMachine\Root` → 后端域名指向本机
→ 起 TLS 接收器 → 启动客户端。

**第一次**（简易证书）：

```
[sni ] <backend>
[tls ] HANDSHAKE FAILED: EOF
```

怀疑是证书字段不全。重新生成一份完全合规的：

```
subject : CN=<backend>, O=DSH Test
eku     : serverAuth
bc      : CA=false
san     : 5 个域名（含通配）
chain   : leaf + CA
```

**第二次**：完全相同，连续 12 次重试全部在 ClientHello 之后断开。

加上 `-insecure` 启动参数（已确认参数确实传入游戏启动器）：行为不变。

⇒ 客户端使用内置固定信任列表，与系统证书库无关。

---

## 3. 进程内存读取 → ✗

`OpenProcess` 成功（含 `PROCESS_ALL_ACCESS`），但 `ReadProcessMemory`
对任何地址都返回 `ERROR_INVALID_PARAMETER`，即使读
`KUSER_SHARED_DATA`（每个进程都映射的只读页）。

`VirtualQueryEx` 正常 —— 说明拿到的是"只能查询"的句柄。

---

## 4. 进程转储 → ✗

`MiniDumpWriteDump` 三种权限组合、两种转储类型，全部 `E_INVALIDARG`。
与 3 同源：缺少 `PROCESS_VM_READ`。

---

## 5. 冻结进程 → ✗

要让密钥所在页"冷却"才能被换出，需要 `NtSuspendProcess`。
返回 `STATUS_ACCESS_DENIED`。
`EmptyWorkingSet` 同样被拒。

---

## 6. 页面文件 → ✗

思路：制造内存压力，让密钥所在页被换出到 `pagefile.sys`，
再用原始卷读取绕过文件锁。

实测：

```
内存压力 22 GB  → 页面文件 980 MB
内存压力 28 GB  → 页面文件 3012 MB（碎片化成 3 段）
```

把 3 GB 全部读出并扫描 24 字符 base64：62 个候选，
**全部来自浏览器 / PowerShell / 日志文本，没有一个来自游戏**。

原因很直接：密钥所在页是**热页**（每个包加解密都访问），
只要进程在跑就不会被换出；而冻结进程所需的权限恰好被剥离了。

（顺带发现：扫描出的 4 个带相关关键字的候选，最后确认是同一台机器上
办公软件的文本内容被换页所致。这个细节说明了扫描器的灵敏度，
也说明"命中关键字"绝不能当作"找到密钥"。）

---

## 7. 强制崩溃 → WER 转储 → ✗

思路：崩溃转储由系统写，权限模型与普通进程不同。

尝试：

```
内存压力 22 GB          → 进程存活
内存压力 28 GB          → 进程存活
显卡驱动重置（热键）    → 进程存活
```

**零份转储产生。** 该进程对资源枯竭与设备丢失都做了恢复处理，
从外部无法在不触碰进程的前提下逼崩。

---

## 汇总

| # | 路径 | 状态 |
|---|---|---|
| 1 | 网关抄包 | ✗ |
| 2 | TLS 中间人 | ✗ |
| 3 | 内存读取 | ✗ |
| 4 | 进程转储 | ✗ |
| 5 | 冻结进程 | ✗ |
| 6 | 页面文件 | ✗ |
| 7 | 强制崩溃 | ✗ |

**在不加载内核驱动、不接入硬件的条件下，到此为止。**

再往下只有两种，且都必须改变前提：

- 内核态读取（驱动绕过权限剥离）
- 硬件读取（PCIe 采集设备，绕过整个操作系统）
